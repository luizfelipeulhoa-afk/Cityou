# Project Timeline Synthesizer

Cria e visualiza linhas do tempo de projeto automaticamente a partir de notas, decisões e marcos espalhados.

## Entrada
Notas, decisões, marcos de documentos dispersos · prazos e datas-alvo · dependências entre tarefas

## Saída
Linha do tempo visual · gráfico de Gantt · análise de caminho crítico · avaliação de risco · planejamento de recursos

## Exemplo: temporada de competição de cheer
```
Fase 1: Preparação de base (Semanas 1-4)
  ├─ Condicionamento físico e avaliação de nível
  ├─ Formação de stunt groups
  └─ Dependência: completar antes da Fase 2

Fase 2: Construção de rotina (Semanas 5-10)
  ├─ Coreografia e stunts
  ├─ Ensaios de piramiÌde
  └─ Dependência: Fase 1 completa

Fase 3: Refinamento (Semanas 11-14)
  ├─ Ajuste fino de sincronização
  ├─ Simulados de competição
  └─ Caminho crítico: garante prontidão pro campeonato

Fase 4: Competição (Semana 15+)
  └─ CBCD/temporada oficial

CAMINHO CRÍTICO:
Fase 1 → Fase 2 → Fase 3 → Competição

RISCOS:
- Lesão de atleta-chave pode adiar Fase 2
- Disponibilidade de espaço de treino na Fase 3
```

## Recursos
✅ Extração de linha do tempo a partir de notas dispersas · ✅ Representação visual · ✅ Análise de caminho crítico · ✅ Identificação de risco · ✅ Rastreamento de dependência · ✅ Alocação de recursos

## Casos de uso reais
Planejamento de temporada de competição · progressão de ano letivo (bimestres, avaliações) · qualquer projeto pessoal com fases e prazos que hoje estão espalhados em notas soltas.
